# Посмотри в окно

Проектная работа третьего спринта курса «Фронтенд-разработчик» Яндекс Практикума.

Одностраничное приложение, которое показывает видео с видом из окон в разных городах и в разное время суток. Данные загружаются из API Яндекс Практикума.

В рамках проекта свёрстаны стили (styles/style.css) по макету из Figma: лейаут страницы, форма поиска с кастомными чекбоксами, карточки видео, кнопки и их состояния, доступность (visually-hidden, фокусные стили).
